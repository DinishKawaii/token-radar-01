Implied value is this board's own claim about what a token would be worth if the protocol's record stayed as it is. It is not a prediction that a token will be issued, or when. “Records no token” means the snapshot's data carries none — a protocol may still have one its record does not carry.

How the value is worked out

Every multiple below comes from this snapshot itself — the median market-cap / TVL of the protocols in that category whose token already trades (only protocols with at least $1m of TVL count). A category with fewer than three such protocols uses the overall median instead. No protocol name is special-cased: the same formula scores every row.

implied = TVL × category multiple × growth × maturity × chains

  • Growth — 1 + (7-day TVL change, clamped to −60%…+120%) × 0.5. A protocol growing fast is worth more than a shrinking one at the same TVL.
  • Maturity — 0.6 + min(age, 3 years) / 3 years × 0.4. A protocol that has run for years with no token has survived longer; one with no listed date counts as one year old.
  • Chains — 1 + 0.02 per extra chain, up to 1.10. Being on more chains reaches more users.
  • Multiple — clamped to 0.05…1.20, so one outlier category cannot produce an absurd value.
